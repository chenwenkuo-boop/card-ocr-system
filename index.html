Google Apps Script 完整程式碼與步驟： 

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // 如果是全新空白工作表，自動寫入第一行欄位標題
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["建立時間", "姓名", "職稱", "公司名稱", "手機", "公司電話", "Email", "網站", "地址", "標籤", "備註"]);
    }
    
    var data = JSON.parse(e.postData.contents);
    
    sheet.appendRow([
      new Date().toLocaleString("zh-TW", { timeZone: "Asia/Taipei" }),
      data.name || '',
      data.title || '',
      data.company || '',
      data.mobile || '',
      data.phone || '',
      data.email || '',
      data.website || '',
      data.address || '',
      Array.isArray(data.tags) ? data.tags.join(', ') : (data.tags || ''),
      data.note || ''
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ result: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({ result: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet() {
  return ContentService.createTextOutput("CardVault Google Sheet Webhook is Live!");

  1. 開啟您的 Google 試算表，點選選單 **「擴充功能」 > 「Apps Script」**。
  2. 清空預設程式碼，貼上上方複製的完整程式碼並儲存。
  3. 點選右上角 **「部署」 > 「新增部署」**。
  4. 類型選 **「網頁應用程式 (Web App)」**，執行身份選 **「我」**，存取權限選 **「所有人 (Anyone)」**。
  5. 點選部署授權後，將產生的 **網頁應用程式網址** 貼入上方欄位中！

發布至 Google 協作平台 (Google Sites) 教學

您可以輕鬆將此智慧名片管理系統嵌入到您公司的 Google 協作平台網站：

步驟一：複製本網頁完整 HTML 程式碼

請將本 HTML 檔案的所有程式碼完整複製。

步驟二：開啟 Google 協作平台 (Google Sites)

在頁面右側工具面板中點選 **「插入 (Insert)」 > 「嵌入 (Embed)」**。

步驟三：貼上程式碼

在彈出的視窗中切換至 **「內嵌程式碼 (Embed Code)」** 頁籤，將本網頁 HTML 程式碼貼入並按下一頁新增。

步驟四：調整尺寸與設定 API Key

拉大嵌入區塊的高度以獲得最佳瀏覽體驗。預覽或發布網站後，點選本系統右上角的 **「系統設定」**，貼入您團隊的 Gemini API Key 與 Google Sheet 網址即可！
